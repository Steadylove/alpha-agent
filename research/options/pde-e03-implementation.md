# E03 实现说明

本说明在 E03 完整收益评估前记录，模型/搜索参数以原 `pde-e03.json` 登记版本为准。

- 对原始报价加入一致性检查：若拟合市场 Q 下已经出现正的成本后期望值，该候选不作为交易信号；同时要求 P 下期望 payoff 大于 Q 下期望 payoff。这样不会把 Q 的拟合残差当作预测优势。
- `neutral_only_quality_gated` 指仅限蝶式、铁蝶、秃鹰等区间结构，并不强制 Delta 等于零。
- 2025-11-28、2025-12-24 的现金/到期期权收盘时间按 13:00 美东处理，不使用其 14:00 快照。其余本次样本现金到期时刻为 16:00。跨夏令时按真实 UTC 时长算特征。
- 历史 API 下载改成同日两个到期日合并查询；保存后仍按原注册的合约日期、到期日及三个时点核对。两个并发请求上限不变。
- 下载传输的后续改进：只取目标时点、尝试按月快照，以及按同一到期日合并相邻决策日期。整月全到期日接口被服务端拒绝，因此没有用它替换任何研究输入。所有有效缓存继续逐日期/到期日/时点校验；传输方式变化不改变注册的观察时刻、模型、候选或参数。若使用 as-of 接口，保留原始报价时间并要求不晚于目标时刻；不将其改写为已成交时间。
- 开发段和后段成绩按持续运行组合的开仓日期分组，跨边界持仓继续占用仓位；不在后段起点假装原有持仓消失。
- 收盘代理收益只在结构及入场决策确定后附加；校准样本和模型选择验证样本均须在本次开仓日期之前完成到期。
