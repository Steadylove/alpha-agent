# 买卖点附图

2H、4H 和通用 Pine 脚本的买卖点告警可附带交易图，Discord 和 Telegram 复用同一张图片。交易规则不变。

买点图以绿色标出当前 K 线的收盘触发价，同时显示历史 K 线和 Vegas 通道。此时尚未实际开仓，不展示未来成交价或卖点。

卖点图中的绿色标记为这笔持仓实际开仓的位置（下一根开盘），红色（亏损）或橙色（盈利）标记为当前卖点的收盘触发价；不把触发价当作下一根开盘的实际成交价。青色通道为 EMA166/169，紫色通道为 EMA576/676，数值来自 Pine 当前图表。

买卖点使用实心价格标签、引线与高亮圆环，标签放在图表上下留白处，避免遮挡 K 线和通道。股票代码在左上角放大，品牌标识在右上角缩小。图片不显示图例，默认 4H 信号不显示周期标记。

## 生效步骤

1. 部署服务端渲染代码。
2. 将对应的 `tradingview-signal-2h.pine` 或 `tradingview-signal-4h.pine` 更新到 TradingView，保存并添加到图表。
3. 删除旧告警，以新脚本重新创建 `Any alert() function call` 告警，沿用原来的 Webhook URL。

TradingView 告警保存的是创建时的脚本与参数副本，仅修改图表脚本不会更新旧告警：[官方说明](https://www.tradingview.com/pine-script-docs/faq/alerts/#if-i-change-my-script-does-my-alert-change)。

## 数据口径

- `entryTime`：卖点告警中的实际开仓 K 线开盘时间，毫秒；`barTime`：当前买点或卖点 K 线的收盘时间，毫秒。
- `chart`：`{ version: 1, stride, bars }`。每行按时间升序排列：`[开盘时间, 收盘时间, O, H, L, C, EMA166, EMA169, EMA576, EMA676]`。
- 买点图回看至多 80 根，只显示截至信号收盘的行情。卖点图默认至少回看 80 根，并尽量包含开仓前 20 根；最多回看 2000 根，压缩到不超过 120 根显示柱。合并时取首根开盘、区间最高最低、末根收盘及末根 EMA，并注明合并根数。
- 只在实时确认的买卖点收盘生成快照，不包含之后的行情。卖点图中开仓早于回看窗口时显示买入价格参考线并明确提示，不虚构买点位置。
- 服务端校验时间顺序、OHLC、EMA、卖点持仓的买入时刻及末根收盘与信号价格是否一致；旧告警或无效附图继续发送原版卡片。买点仍需通过原 RPS 闸门才推送。卖点照推，并同样展示相对大池分位；买卖点都展示 ATR 金额及占信号价比例。旧卖点告警没有 `atr` 时只缺这一栏。

本地测试与图片预览验证服务端协议及渲染。Pine 仍需在 TradingView 保存编译，并在新告警首次触发时核验 Webhook；本地 TypeScript 测试不能代替 Pine 编译。
