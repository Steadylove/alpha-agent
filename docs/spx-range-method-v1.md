# SPX 收盘区间计算方法 v1

## 当前决定

固定 **SPXW 期权隐含区间** 为研究主方法。先评估区间预测，后续再研究如何选择蝶式、铁秃鹰、到期日、入场时点和退出规则。

| 项目 | 固定口径 |
|---|---|
| 方法编号 | `spx-close-range-v1` |
| 预测目标 | 指定交易日的 SPX 最终现金指数收盘点位 |
| 主方法 | SPXW 看涨/看跌期权中间价 → 隐含远期中心和总波动率 → 收盘区间 |
| 输出 | 中央 68% 与 95% 区间；注明数据时点、目标日、来源和方法版本 |
| 已验证输入时点 | 目标交易日美东 10:00，同日到期、PM 结算的 SPXW 期权链 |
| 对照模型 | 以前 60 个完整日收益计算的盘前历史波动模型 |
| 实验模型 | 使用此前标准化预测误差调整宽度的校准模型，暂不替代主方法 |
| 外部对照 | 博主公开区间，仅参与比较，不进入我们模型的输入 |

区间描述最终收盘；盘中可能越界。68% / 95% 是模型标称覆盖水平，实际覆盖率另行统计，也不等于交易盈利概率。

## 计算步骤

### 1. 选取合格期权报价

只使用预测时点对应的期权链，Call 与 Put 必须具有相同行权价、到期日和快照时刻。使用中间价 `(bid + ask) / 2`，其作用是估计分布，不表示可以按中间价成交。

固定筛选条件：

- 买价为正、卖价不小于买价，两侧挂单数量均至少为 1。
- 每条腿买卖价差不超过 1 个指数点。
- 按 `abs(Call中间价 − Put中间价)` 从小到大选最多 7 对；不足 3 对则拒绝预测。
- 各对期权推导的远期中心最大值与最小值之差不超过 2 点。
- 分钟快照不能单独证明所有原始报价都足够新鲜；若未来增加报价年龄检查，应记录新版本。

### 2. 计算中心

对每一对 Call/Put，以行权价 `K`、Call 中间价 `C`、Put 中间价 `P` 计算：

```text
F_i = K + C − P
F = median(F_i)
```

这是将短期限折现因子近似为 1 后的平价关系。`F` 表示隐含远期中心，不是假定必然回归的目标价。这个近似属于当前同日短期限版本，不能不经检查直接扩展到较长到期日。

### 3. 反解剩余期限波动

使用 Black 跨式定价公式，使模型的 Call 与 Put 价格之和等于观察到的 `C + P`，数值求解 `w = σ√T`：

```text
d1 = ln(F/K)/w + w/2
d2 = d1 − w
Call + Put = F × [2Φ(d1) − 1] − K × [2Φ(d2) − 1]
```

`Φ` 是标准正态分布函数。每对报价得到一个 `w`；至少需要 3 个有效解，再取其中位数。直接估计总波动 `w`，避免为了展示年化 IV 而引入额外时间换算。

### 4. 输出区间

对于标称覆盖率 `c`，固定公式为：

```text
z = 标准正态分布的 (1+c)/2 分位数
中心中位数 M = F × exp(−w²/2)
下界 = M × exp(−z × w)
上界 = M × exp(+z × w)
```

分别代入 `c = 0.68`、`0.95`。保留原始小数作为评价依据；交易时如何将区间映射到行权价属于后续策略规则。

本版使用平值附近的对数正态近似，尚未完整刻画波动率偏斜、厚尾、跳跃或经济事件。期权价格反映的是定价分布，实际概率需要用后续结果检验。

## 时点可以扩展，历史成绩必须分开

10:00 是目前已验证的采样时点，不是数学公式只能运行的时刻。以后可以研究：

- 前一交易日收盘附近，使用下一交易日到期的期权链预测次日收盘。
- 目标日开盘后更早或更晚的快照。

每一种时点都需要单独固定 `报价日期 + 报价时刻 + 到期日 + 目标收盘日`，核验报价与交易日历，并使用该预测跨度的历史误差和独立成绩表。不能把 10:00 的覆盖率或校准误差用于前一晚的预测。已有 v1 保留；新时点、数据过滤或数学变化登记新版本再评估。

当前 `forecast.py` 的数据读取仍是同日 10:00 档位；前一日的期权预测没有在本次实现。盘前日线下载仍只纳入美东当前日期之前的数据，收盘后立即出下一日初版的采集调整另行处理。

## 评价与变更规则

1. 每个预测使用当时已经可得的输入，不能以未来收盘调整当天范围。
2. 同时报告覆盖率、全宽、越界距离、区间评分、拒绝预测日期和逐月表现。
3. 区间评分为 `全宽 + 2/(1−c) × 越界距离`；同时惩罚过宽与漏报。
4. 比较模型时采用相同交易日；若发布时间不同，要明确各自的信息范围。
5. 预测失败要保留原因；不临时换成另一模型、不把缺失算作命中。
6. 历史重建与结果发生前实际生成的记录分别标注。固定方法不等于消除过拟合。
7. 调整期权组合或盈亏目标时，不倒过来修改预测区间让回测更好看。若确需修改预测方法，创建新版本并重新检验。

采用本方法时已观察到的近期结果：36 个有效期权预测，68% 区间覆盖 28 天、95% 区间覆盖 35 天；另 2 天报价不合格。它们是已查看的回溯样本，不是未来表现保证。
