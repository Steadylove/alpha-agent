# PDE 概率密度优势期权系统：核心思想与当前策略路线

分析日期：2026-09-16。

原文：用户提供的《PDE 概率密度优势期权系统.pdf》，38 页，标题为 `Master Agent Prompt v1.0`。文件 SHA256：`d569dbaeff026efa9b263dcb5db7224f4a1a1c8b08b6c922752e812d5cc3b6b9`。

本文把原文作为待分析的研究方案。文中的角色指令、Phase 0 指令和交易授权要求不是本次执行任务；本次任务是提取思想、核对现有工程和提出研究路线。原文没有提供数据集、已估计参数、样本外收益表或实盘成绩。

## 一、结论

这份文档最有价值的部分，是把“预测一个区间然后固定做铁秃鹰/蝶式”改成：

**估计收盘分布 → 计算各组合的概率加权盈亏 → 扣除交易成本 → 检查尾部与资金风险 → 选择交易或不交易。**

它适合作为研究框架，但尚不能作为已证明盈利的策略。真正困难的环节是：得到足够可靠的现实概率估计，并证明据此选择的组合在成本和风险之后仍有价值。密度积分本身是期望值计算，不会自动创造优势。

对当前项目的建议是：保留已冻结的区间 v1，作为简单的市场隐含分布参考；新增分布查询和组合期望收益评价，在新的实验版本里检验现实概率模型。先复用 SPXW、本地缓存和现有回放代码，无需重建整个项目。

## 三、必须澄清的数学与交易边界

### 1. 市场定价分布 Q 与现实概率分布 P

- `Q`：用于解释当前期权价格的风险中性分布，含风险定价信息。
- `P`：希望估计的未来实际价格分布，用真实后续结果检验。
- 当前 v1：从平值附近期权反解一个对数正态分布，可记为 **Q₀ 近似**。它没有重建全行权价的波动率偏斜，也不能直接当作已验证的 P。
- 盘前历史波动模型是另一种预测基准，但与 10:00 剩余日内期限的信息条件不同，不能直接与其混合比较。

原文已区分 P/Q，这一点正确；但“P 与 Q 不同”还不能直接解释为市场错误。差异可能来自风险溢价、承担坏状态损失的补偿，或模型本身有误。即使发现正的平均收益，还要评价所承担风险是否值得。[美联储研究：The Pricing Kernel in Options](https://www.federalreserve.gov/econres/feds/the-pricing-kernel-in-options.htm)

同一批期权价格既用于反推分布，又用于发现这些期权“便宜”，容易形成自我验证。若在一致模型下用 Q 定价，同一组合的折现期望收益应与该模型价格吻合；买卖价差和费用会降低可实现结果。当前简化 Q₀ 与真实报价之间的残差，可能只是忽略偏斜、报价噪声或拟合误差，不能直接叫 Alpha。

### 2. 两个区间不能唯一决定一个分布

相同的 68% / 95% 区间，可以对应不同的中心集中程度和尾部形状，交易盈亏可能完全不同。

我们的 v1 已经保存 `F` 和总波动 `w`，并作出对数正态假设，所以能在这个假设内直接计算 PDF、CDF、任意分位数和区间概率，无需蒙特卡洛。比如：

```text
ln(S_T) ~ Normal(ln(F) - w²/2, w²)
CDF(K) = Φ((ln(K/F) + w²/2) / w)
P(a < S_T < b) = CDF(b) - CDF(a)
```

扩展输出不等于新增预测信息。现有“绝对误差分位数校准”只调整对称区间宽度，也不能直接升级为可信的完整非对称分布。要研究左/右尾，需要有符号误差及足够历史。

### 3. 完整市场密度是诊断工具，不必成为第一步的工程障碍

从一串欧式看涨期权价格相对于行权价的曲率，可以恢复风险中性状态价格信息，这是 Breeden–Litzenberger 的思路。[原论文摘要](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2642349)

实际报价离散且带噪声，不能对原始中间价直接二次差分后把负密度截成零就算完成。需要检查价格随行权价递减、凸性、买卖盘容差、尾部外推、总概率以及重新定价误差。离散报价范围外的尾部不能被数据唯一确定。

第一轮可以直接比较 **P 下的期望到期收益与市场真实组合报价**，不必等到完整 Q 密度拟合完毕；Q₀ 和后续更完整的 Q 用作基准与诊断。

### 4. 净期望收益必须统一符号、单位与成本

令 `g_a(S)` 为一组组合的到期现金收益，已经包含各腿方向、张数和合约乘数；`C_exec` 为有符号的净支出：买入组合为正，收取信用为负。

```text
EV_P = D × ∫ g_a(S) f_P(S) dS - C_exec - 费用与额外滑点的现值
```

`D` 为到期现金流折现因子；本轮同日短期限可明确采用近似 1，跨日时统一资金成本口径。所有量均用美元，不能将指数点与美元直接相减。

买 ask、卖 bid 的 `C_exec` 已包含买卖价差影响；不要再次扣一份相同的 spread。显式手续费、报价以外的滑点与资金成本另列。若定义的 payoff 已包含开仓成本，也不能再扣一次。

原文的 `J = EV - 风险惩罚 - 成本...` 是概念框架，还没有给出惩罚系数与风险单位。初期更容易审计的做法是：先用最大损失、资金占用、尾部损失和报价质量作硬约束，再比较成本后的期望收益及其估计不确定性。

### 5. 终值密度不描述盘中路径

`f(S_T)` 足以计算普通欧式组合持有到期的收益分布，但不能独自回答：

- 盘中是否触发止损；
- 先碰止盈还是先碰止损；
- 15:30 能以什么价格退出；
- 最大浮动回撤是多少。

这些问题需要路径以及当时的期权重估/可成交报价。仅模拟 SPX 路径而不处理隐含波动变化，也不能得到可靠的期权退出价格。原文第 18–19 页的退出研究必须作为后续独立模块。

另一个输出细节：连续分布中，标准买入蝶式恰好达到单一点位的最大利润概率为零；平台型最大收益区间可以有正概率。`P(max profit)` 必须按结构和离散结算口径定义，不能统一计算为“落在中心附近”。

### 6. “最佳入场时间”不能看完一天再挑

原文的 `argmax` 是目标函数表达。回测执行必须只利用每个时点当时已知的信息，按预定规则选择交易或等待；不能把当天所有时点的最终盈亏算完，再挑最赚钱的那个当作真实交易。跨到期日与多腿大范围搜索同样需要控制选择过拟合。

## 五、当前策略应怎样推进

### 第一步：把 v1 作为固定参考，补充分布接口

在新研究模块中读取 v1 的 `F`、`w`、输入时点与来源哈希，提供：

- CDF/分位数/任意价格区间概率；
- 标准化价格网格及概率质量；
- 左右尾概率；
- 数据质量与可用性标签。

保留 v1 的公式、参数和历史记录。概率语义明确写为市场隐含近似，不将已有 97.2% 历史覆盖率包装为每笔胜率。

### 第二步：做组合期望收益评价，先让算术与报价自洽

第一轮继续使用已有 SPXW、同日到期、美东 10:00 的数据，是为了复用已有样本、减少同时变化的因素，不是在断言 0DTE 或 10:00 最优。

先限定少量定义风险结构：标准买入蝶式、铁秃鹰、看涨/看跌垂直价差。对于每组候选输出：

- 净支出/收入、手续费和资金占用；
- 最大利润、最大损失、盈亏平衡点；
- 在明确标注的 P 或 Q₀ 下的胜率、预期收益、预期亏损、尾部损失；
- 对报价与模型误差敏感的程度。

只比较持有到期的基础结果；现有盘中退出研究保留为另外的实验。每种结构使用同一份预测数据，不给不同结构事后挑最有利的分布。

**必要的负对照**：先用一个已知 Q 生成无套利合成期权链。用同一 Q 对任何组合积分，折现期望 payoff 应等于模型组合价格；加入价差与费用后，不应凭空出现系统性正收益。若失败，先检查积分、乘数、买卖方向、单位和重复扣费。

对真实链，Q₀ 重定价残差单独记录为“简化模型拟合误差”，不能直接成为下单信号。

### 第三步：寻找现实概率 P 的增量信息

第一候选优先研究“期权隐含波动与随后实际波动之间的关系”，不先假定价格会回归某个 Gamma 墙。

可研究同一预测时点/期限下、有符号的历史标准化误差分布：保留偏度和尾部，所有样本只来自此前日期。它是在检验市场隐含尺度如何映射到实际结果，不是把 Q 自动变为 P。

现有 36 天可以做程序连通性和初步诊断，但不足以可靠估计 1% / 5% 尾部、复杂状态条件或稳定收益。已有 20–60 天绝对误差校准窗口也不足以支撑这些扩展。

在现有套餐内优先补齐更长的同一时点、同一期限历史；例如先争取 6–12 个月用于初步滚动研究。这个长度是研究起点，不是充分证明尾部风险已被覆盖。保留固定的未来连续样本，规则更改另建版本；已经查看的历史不能重新称为未触碰测试集。

评价时同时看分布质量与经济价值：覆盖/宽度、PIT 或校准曲线、CRPS、明确阈值事件的 Brier 分数、尾部漏报与成本后收益。各日期存在依赖，置信度估计需考虑时间相关性。

### 第四步：有证据后才让分布影响选仓

候选结构的倾向可以解释，但不能直接写成机械交易信号：

| 经验证的差异 | 可以进入比较的结构 | 必须额外检查 |
|---|---|---|
| 某个中心附近的概率质量被低估 | 买入蝶式 | 蝶身位置、支付价格、尾部及错位损失 |
| 保护区间外的实际尾部损失低于市场所收的保险价格 | 铁秃鹰或信用价差 | 尾部估计不确定性、风险补偿、保护翼和可收权利金 |
| 上下方向或偏度有增量信息 | 方向性垂直价差 | 是否已被报价反映、执行成本 |
| 分布差异不稳定，或价格已充分反映 | 不交易 | 记录原因，避免为了保持交易频率而放宽标准 |

先按最大亏损、整数合约、账户预算和可成交性排除不合格候选，再比较净 EV 和压力情景。账户规模未知时不把“一组组合赚多少”换算成账户收益率，也不设月收益目标倒逼开仓。

### 第五步：再扩展时点、期限与增强特征

- 提前一天预测：需要前一日快照与下一交易日到期期权，单独建档和回测。
- 1DTE / 更长期限：处理折现、期限差异与独立的概率校准，不能沿用同日胜率。
- GEX/OI/Flow：逐项检查新增信息，不使用不可观测的“真实 Dealer Inventory”假标签。
- 盘中止盈止损：补齐被选择合约的路径报价，单独评价可执行性与下一时点成交假设。

## 六、第一轮最小实验的具体交付物

建议实验名：`PDE-E01：分布与组合现金流一致性`，它是工程验证，不是盈利证明。

| 项目 | 建议内容 |
|---|---|
| 数据 | 现有 38 天 10:00 快照；36 天主模型有效预测；沿用固定的质量拒绝记录 |
| 计算方法 | 对数正态解析公式或确定性数值积分；无需 6,000 条蒙特卡洛路径 |
| 结构 | 少量固定候选蝶式、铁秃鹰与垂直价差，加入“不交易” |
| 最先运行 | 已知分布的合成链测试、相同 payoff 的直接现金流核对 |
| 真实数据输出 | 组合报价、分布下期望 payoff、拟合残差、成本、最大风险与数据缺口 |
| P 的处理 | 可做历史误差研究对照；明确小样本限制，不把探索估计用于实盘 |
| 成功条件 | 概率质量、价格与美元单位一致；无套利合成链不凭空产生 Alpha；质量失败可追踪 |
| 下一阶段条件 | 更长历史和固定未来样本中，P 的改进可转化为成本后、风险可接受的结果 |
| 新增采购 | 这一轮本地计算不需要追加数据购买；已有订阅费用仍然存在 |

不必照抄文档目录重建 `pde/` 工程。当前可复用 `range_model.py`、`forecast.py`、`replay.py` 与 `optimize.py` 中已经验证的部分，在相邻新模块里补分布查询、现金流积分与实验登记即可。
