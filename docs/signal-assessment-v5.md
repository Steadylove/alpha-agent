# 买点五因子 V5：并行候选版本

## 本次落地

V4 继续作为线上展示和入场复盘的基线。新买点的不可变快照额外保存 V5 候选分、原始特征、板块来源和独立止损信息。旧买点重放不补写候选，也不改旧评分。V5 预览显式标记“试算”。本次不改变买卖条件，不用总分自动下单。

| 因子 | 权重 | 变化 |
| --- | ---: | --- |
| RPS 强度 | 30 | 保持 V4 的前一交易日日线排名 |
| 位置 | 25 | 快 Vegas 通道/ATR + 结构方向 + WR 恢复状态 |
| 量价压力 | 20 | 保留分钟 OHLCV 估算的 CVD；不是逐笔主动成交 |
| 板块共振 | 15 | 新增相对强度与标普板块广度，替代止损评分 |
| 成交分布 | 10 | 保留估算 POC、70% 价值区和低成交量区 |

缺项不补零、不放大剩余得分，也不授予完整评级。30/25/20/15/10 是冻结的首轮研究权重，没有证明优于文档里的 25/25/20/15/15，更不代表经过收益优化。

## 位置：固定定义、保存原始特征

- 只用截至买点收盘的未压缩原周期 K 线，至少 38 根。
- `WR(N) = -100 × (最高价N - 收盘价) / (最高价N - 最低价N)`，范围 -100～0；`PLI = WR + 100`。
- 保存 WR14、WR34、WR34 的最近 5 根均值、WR14 的 3 根变化、`WR34-WR14`（同样等于 PLI34-PLI14）、价格回升标记、超卖恢复标记。
- WR34 平滑是中期指标的降噪版本，不称为独立的长期指标。
- 快通道参考价固定为 EMA166/169 中线。`distanceAtr = (收盘价 - 快通道中线) / ATR`。负数表示价格在快通道下方。价格跌破快通道时，不切换到慢通道来美化距离。
- 多头结构：快通道整体高于慢通道 EMA576/676，快通道近 3 根斜率大于零，慢通道斜率非负。价格低于慢通道下沿标记“慢通道失守”。
- 价格回升需收盘价高于前一根。WR 与价格同步回升，且最近 3 根曾低于 -80、当前收复 -80，才标记恢复；极值滚出窗口造成的 WR 上升不单独加恢复分。

首轮显示映射（固定后再研究，不是最优阈值）：

| 部分 | 规则 |
| --- | --- |
| 结构 | 确认多头 8；其余未失守 4；慢通道失守 0 |
| 距离 | 绝对偏离 ≤1、≤2、≤4、>4 ATR，分别 8、6、3、1 |
| 恢复 | 超卖恢复且价格确认 9；普通同步回升 5；其他 2 |
| 限制 | 结构未确认最多 15；偏离 >4 ATR 最多 12；慢通道失守最多 5 |

高位维持和回调观察都有中性基础分；不因 WR 高而自动扣分。偏离较大限制加分，不再把整个位置项乘成零。WR34、平滑值和位置差当前只留作研究特征，不额外叠加一轮相关分数。

## 板块共振

1. 每次构建日线 RPS 时，同时构建板块快照。
2. 11 个 SPDR 板块 ETF 的 20 交易日收益率减 SPY 同期收益率；用完整 11 板块横截面生成 0～1 分位，同值取中间名次。
3. 广度 = 所属板块中收盘价高于自身 SMA50 的有效标普成分股 / 有效标普成分股。要求与 SPY 最近 50 个交易日逐日对齐；缺任何一天即该股票无效。
4. 每板块至少 10 个有效样本，覆盖率至少 95%；任何一个 ETF 缺少动量数据，横截面分位不生成。
5. 初始显示分 = `15 × (板块动量分位 + 广度比例) / 2`。这不是预测概率，也不是最优权重。
6. 广度仅表示**标普成分股中的对应大板块**，例如 XLK 信息科技，不冒充整个半导体行业广度。DELL 等样本自身会包含在其板块广度内，因此与个股 RPS 仍可能相关；后续研究可比较剔除目标股票后的广度。
7. 默认分类来自 `datasets/s-and-p-500-companies` 当前名单。未知归属不默认科技；ALAB 由[公司产品说明](https://www.asteralabs.com/about/)核验后人工映射到信息科技，仅用于参照板块，不把它加入标普广度样本。核验日期和来源随快照保存。其他非标普股票暂时可能缺板块项。
8. 线上必须匹配 RPS 的前一交易日，且快照、分类不能晚于信号；历史预览单独显式允许事后重建，并标注来源日期。

## 风险独立

参考止损、距止损百分比、ATR 仍在卡片上。股数辅助函数只计算 `floor(计划亏损金额 / (信号价 - 止损价))`，不参与质量分；这是按止损成交的预算，未包含跳空、滑点、费用或资金上限。未设置用户账户仓位或自动交易。

## 后续验证口径

冻结这版规则后，使用可证明当时已知的完整数据并行记录 V4/V5。在同一批买点、相同出入场与费用下，分开比较：原位置、只替换位置、只替换板块、两者同时替换、不同总权重。关注 MAE、MFE、扣费后期望、利润因子及交易数量；按时间分离训练和样本外测试，不能在同一批数据上选阈值再报“提升”。本次完成实现和真实卡片校验，尚未给出 V5 收益改善结论。
