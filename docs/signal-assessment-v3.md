# 买点位置评分 V3：Vegas 距离与 Williams %R

> 当前权重已更新至 [V4](signal-assessment-v4.md)。本文保留 V3 的 15 分位置口径；V4 沿用本页判断规则，按比例调整为 25 分。

## 范围

五个因子仍为 CVD 背离 30、强度 25、位置 15、风险 15、成交分布 15。只调整位置因子；买卖信号、Vegas 趋势过滤、RPS 闸门、止盈止损和仓位规则不变。卡片保持总分和五项分数的简版展示，不添加表情或解释段落，标题标注 V3。

这是一版固定的观察规则，**8/7 权重及恢复阈值没有经过收益标定或样本外验证，分数不是盈利概率**。上线评分不等于改变交易选择，也不能证明策略收益提高。

## 计算

只读取买点当时已确认收盘、经过时间及 OHLC 校验、`stride=1` 的图表快照。不另请求行情，不使用信号之后的价格。WR14 的周期是 14 根当前图表 K 线；4H 图使用 14 根 4H K 线，不是 14 天。

### Vegas 距离，最多 8 分

沿用 V2 的通道和 ATR 口径。候选通道为价格不低于其下沿的 EMA166/169、EMA576/676 通道。价格在通道内时距离为 0，在上方时取至上沿的距离，选最近的一组，再除以信号 ATR。

```text
d = 距最近下方通道的距离 / ATR
接近系数 = clamp(1 - d / 4, 0, 1)
Vegas 分 = 8 × 接近系数
```

价格在两组通道下方时，有效资料下位置总分为 0，不把上方均线当成支撑。

### WR 恢复，最多 7 分

```text
WR14 = -100 × (14 根最高价 - 当前收盘价) / (14 根最高价 - 14 根最低价)
```

分别计算当前根和前三根的 WR14，因此至少需要 17 根未压缩 K 线。

| 当时状态 | 恢复基础分 |
|---|---:|
| 当前 WR 高于上一根，且当前收盘价高于上一根；前三根至少一根 WR < -80，当前 WR ≥ -80 | 7 |
| 当前 WR 和收盘价同时上涨，但不满足上述近期超卖恢复条件 | 3 |
| 其他状态 | 0 |

```text
WR 分 = 恢复基础分 × 接近系数
位置总分 = Vegas 分 + WR 分，按现有规则保留一位小数
```

恢复分也受距离限制，避免价格已经远离均线，仅凭 WR 回升拿到高分。只超卖且继续下跌不加恢复分；超卖区内反弹先给一般恢复分；高位继续上涨也可得一般恢复分，不因“超买”直接清零。同步要求实际收盘价上涨，防止旧极值滚出计算窗口、价格未上涨却获得恢复分。这仍不能证明订单流承接或未来上涨。

举例：贴近通道、没有同步回升为 8/15；贴近通道、一般回升为 11/15；贴近通道、近期超卖后收复为 15/15；后者高出通道 2 ATR 时为 7.5/15，达到 4 ATR 时为 0/15。

## 缺项和历史兼容

- 不足 17 根、压缩图、缺少有效 ATR/末根均线、任一所需 WR 窗口最高价等于最低价时，位置整项标为缺失，不将剩余分数放大。
- 未来、乱序、过期或与信号价格不符的图表继续由原校验拒绝。
- 新评分记录为 `quality-v3`。保存的 V1/V2 入场记录不重算、不覆盖；V2 卡片保留原五项分数并显示 V2，卖点继续取冻结的入场评分。
- 完整计算理由保存 WR 前后值、恢复状态、Vegas 距离和两部分得分，方便核查。
